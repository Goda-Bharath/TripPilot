# TripPilot

A full-stack bus booking web application built with React and Django REST Framework.

## 🚀 Project Overview

TripPilot is a web-based bus booking application that allows users to browse available buses, select seats, register and log in, and manage their bookings.

The project was developed to practice full-stack web development using React on the frontend and Django REST Framework on the backend.

## ✨ Features

- User Registration
- User Login
- Authentication
- Browse Available Buses
- View Bus Details
- Select Bus Seats
- Seat Booking
- View User Bookings
- Responsive User Interface
- REST API Integration
